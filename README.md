# CharaNest

让你的角色住进电脑。

## 当前版本

`0.4.0-beta.5`

当前支持 **macOS Apple Silicon**。

## 功能简介

- 自定义角色
- 桌面陪伴
- Chat
- Focus
- Room / Garden
- 角色管理

## 下载

Beta 下载即将开放。

## 安装提示

当前版本尚未经过 Apple notarize。首次启动时，可能需要右键点击 CharaNest 并选择“打开”。
